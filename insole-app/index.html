Download saves the CSV to this computer or phone; Share sends it to Files / Drive / e-mail on a phone. Clearing the browser's site data removes these logs, so download the ones you need.

Body-weight calibration

The 7 sensors cover only part of the sole, so Σ sensor force reads below the real foot load. Standing still on one foot puts your whole body weight on it: scale = body weight / Σ sensor force. With BW scale on, vGRF and its results are multiplied by this factor.

Σ — N

Calibration: F = a · Gb per sensor

G (µS) = (mV / base − 1) / RF × 10⁶, RF = 39 kΩ. Defaults are fitted from S1-S7test results.xlsx (UTM rigid plate, 0 → 1000 → 0 N, saturated points and missing readings excluded), one sensor per channel. The right foot uses the same values until its own sensors are calibrated. "Base" is the zero-load mV now in use (set by Zero; the test's base until then).

Calibration check: does each channel's mV → N conversion match its UTM data?

Runs the app's own conversion (the coefficients above, hysteresis setting included, base = the test's zero mV) over UTM hold points and compares with the UTM force. Built-in data: S1-S7test results.xlsx (the data the defaults were fitted on, so this checks the coefficients in use) and, for ch1, the independent S1 3-round run (UTM_S1_20261027_230602_CAL, RF 39k). Saturated points (≥ 3250 mV) and 0 N points are left out. Verdict: max error within ±52 N (the S1 RSS budget, 5.2 % FS) and bias within ±20 N.

IMU mounting (BMI270 on the insole)

Which sensor axis points to the toes and which points up out of the insole. Used for foot pitch, eversion, foot progression angle and the live angles. Check: standing flat, the live pitch and eversion should read ≈ 0°, and |a| ≈ 1.00 g.
